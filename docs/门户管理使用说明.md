# 门户管理使用说明（系统主管理员）

一个「门户」就是一个独立的维修业务工作区，可以代表一家门店。所有门户使用同一套功能，但客户、维修单、目录、维修师、设置和备份相互隔离。一个账号可以加入多个门户。

日常管理只需要网页，不需要终端、SQL 或任何命令。

## 1. 登录后会看到什么

- **普通账号**
  - 没有加入任何门户：显示“尚未分配门户，请联系管理员”。
  - 只加入一个门户：直接进入该门户的工作区。
  - 加入多个门户：先出现「选择门户」页，选一个进入；工作区左上角显示当前门户名称和“切换门户”。
- **系统主管理员**：除了上面的规则，还能在 **设置 → 门户管理** 里管理所有门户。没有任何可进入的门户时，登录后直接进入门户管理页。

## 2. 进入门户管理

1. 用系统主管理员账号登录。
2. 左侧菜单点 **设置**。
3. 在设置页最上方的 **门户管理** 卡片点 **打开门户管理**（门户选择页也有同名按钮）。

地址固定为 `/#/settings/portals`。普通门店管理员和员工打开这个地址只会看到“没有权限”。

## 3. 新增门户

1. 点 **新增门户**。
2. 只需输入门户名称（1–80 个字符），点 **创建**。
3. 系统会自动：建立这个门户、建立一份空白的门店设置、把你加为这个门户的管理员。业务数据不会从别的门户复制。
4. 打印抬头、门店电话、条款等，请进入该门户后在它自己的 **设置** 页填写。门户名称只是选择入口用的名字。

如果网络中断导致没有看到结果，直接再点一次创建即可，不会重复建两个门户。

## 4. 改名、停用、启用

- **改名**：只改选择入口显示的名字；订单、二维码、打印资料、成员都不变。
- **停用**：会先弹出确认。停用后成员无法进入，客户扫码查询页暂时不可用；**数据全部保留**，随时可以重新启用。
- **启用**：点该行的 **启用**。改名或分配成员不会自动启用一个已停用的门户。

没有“删除门户”的功能。

## 5. 给已有账号分配门户

1. 在门户所在行点 **分配账号**。
2. 弹窗上方是这个门户的当前成员，可 **编辑** 权限或 **移出**。
3. 在“按完整用户名查找已有账号”里输入准确的用户名，点 **查找**。
   - 找到后选择角色：
     - **本门户管理员**：拥有这个门户的全部页面权限，可以在原“员工”页管理本门户人员。
     - **普通员工**：勾选允许访问的页面；允许一个都不勾，该账号进入后会看到“尚未分配页面权限”。
   - 提示“账号不存在”时，请先在任意一个你是管理员的门户的 **员工** 页创建账号，再回来分配。系统不会自动注册账号。
4. 点 **保存分配**。对方下一次刷新页面即生效，不需要重新登录。

说明：

- 每个门户至少要保留一位门户管理员，最后一位不能移出或降级。
- 你可以把自己移出某个门户，系统主管理员身份不受影响。
- 把自己加入某个门户后，才能按成员权限查看它的订单、财务和备份；系统主管理员身份本身不能直接查看任何门户的业务数据。
- 门户管理页不能修改任何账号的姓名、用户名、邮箱、密码，也不能授予或取消系统主管理员身份。

## 6. 原“员工”页现在的规则

- 列表只显示当前门户的成员。
- 新增员工 = 创建一个新账号并加入当前门户；用户名全站唯一，已被使用会提示。
- “移出门户”只解除该账号与当前门户的关系，账号本身和它在其他门户的身份不变。
- 只有**只属于当前门户、且不是系统主管理员**的账号，才能在这里修改姓名、用户名、邮箱和密码。属于多个门户的账号和系统主管理账号的密码，由维护人员用受控命令重置（见运维说明）。
- 修改密码后，该账号所有已登录的设备都会被退出。

## 7. 备份与恢复

- 备份、导出、下载、恢复都只针对当前门户的业务数据；不包含账号、成员和登录会话。
- 恢复不会改变账号、权限、门户名称或启停状态。
- 升级前导出的旧格式备份（没有门户标记）只能由 **默认门户** 的管理员在确认提示后导入。

## 8. 常见情况

| 情况 | 处理 |
|---|---|
| 提示“门户信息刚被其他人更新，列表已刷新” | 有人同时改了这个门户，核对最新内容后再提交一次 |
| 提示“安全校验失败：请求来源不被允许” | 部署配置 `REPAIRNOTE_PUBLIC_ORIGIN` 与浏览器访问地址不一致，请联系部署负责人 |
| 提示“当前门户已停用或你已被移出” | 回到门户选择页选择其他门户；如需恢复，由系统主管理员重新启用或重新分配 |
| 忘记系统主管理员密码 | 由维护人员在服务器执行 `node scripts/portal-admin.mjs reset-password --staff-id <账号ID>` |
